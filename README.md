# Portfólio de Interfaces Web

Coleção de páginas e exercícios de desenvolvimento front-end criados com **HTML**, **CSS** e **JavaScript**. O repositório reúne exemplos independentes de landing pages, layouts comerciais, galeria de imagens e interações básicas no navegador.

## Sobre o projeto

Este projeto demonstra práticas de estruturação de conteúdo com HTML semântico e estilização com CSS, incluindo layouts com Flexbox e Grid, adaptação para diferentes tamanhos de tela e componentes visuais reutilizáveis. Também inclui um exercício de lógica com JavaScript.

Cada arquivo HTML é uma página independente; não há dependências de frameworks nem etapa de compilação.

| Arquivo | Descrição | Estilos |

| `cachorro.html` | Galeria de imagens de cachorros com arquivos locais. | `fundo.css` |

| `paginareal.html` | Outra página de apresentação de produto e benefícios. | `fundo3.css` |

## Tecnologias

- **HTML5** para a estrutura e o conteúdo das páginas.
- **CSS3** para cores, tipografia, layouts e ajustes responsivos.
- **JavaScript** para a interação da calculadora em `label.html`.

## Como visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Kaliwl/html.git
   ```

2. Entre na pasta:

   ```bash
   cd html
   ```

3. Abra qualquer arquivo `.html` em um navegador. Também é possível abrir a pasta no Visual Studio Code e usar uma extensão de servidor local.

## Recursos

- As imagens da galeria de cachorros e da página de sucos estão na pasta `img/`.
- Algumas páginas carregam imagens ou fontes de serviços externos; esses recursos podem exigir conexão com a internet.
- `proxima2.css` está incluído como folha de estilos adicional, mas não é referenciado pelas páginas HTML atuais.
